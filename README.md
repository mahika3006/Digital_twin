# Digital Twin
### Geospatial Mapping & Building Height Analysis

A collaborative geospatial project bringing together building
footprints, height data, and a QGIS workspace for exploring
the built environment.

## Project Files

| Component | Description |
|-----------|-------------|
| QGIS Project | Workspace for viewing and working with geospatial layers |
| Building Height Rasters | Raster datasets containing building height information |
| Building Footprints | Polygon datasets with building height attributes |
| CSV Data | Tabular building height data |

## Getting Started

1. Download or clone this repository.
2. Open `Kalkaji_Earth_Engine_Data.qgz` in QGIS.
3. If any layers are missing, update their source paths to the downloaded files.
4. Explore the available building footprints and height layers.
